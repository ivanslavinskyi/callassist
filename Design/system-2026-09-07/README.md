Редакция 02: иконки солнца/луны и бургер-меню, общий футер, отдельный пункт «Завершённый звонок и оценка качества».

Откройте `index.html` для всех макетов. Навигация слева выбирает экран; сверху находятся состояние, тема, ширина и язык. Ссылка «Открыть отдельно» убирает панель атласа. Полная страница прокручивается внутри превью. Все новые страницы ждут дизайн-ревью; ранее утверждена визуальная основа dashboard.

- `boards.html` — галерея 132 browser PNG: 33 экрана × 2 устройства × 2 темы; три обзорные ImageGen-композиции.
- `guidelines.html` / `GUIDELINES.md` — шрифты, цвета, типографика, размеры, сетки, компоненты, состояния, доступность, локализация.
- `page-specs.html` / `PAGE-SPECS.md` — поля, порядок, действия, ограничения всех существующих страниц, включая админку.
- `coverage.html` / `manifest.json` — 30 маршрутных/контентных экранов + отдельный завершённый звонок + 2 системных листа, 162 просмотрочных состояния, связь с компонентами репозитория.
- `tokens.css`, `tokens.json`, `assets/` — значения и исходные ресурсы для будущего переноса.
- `qa.html` / `QA.md`, `design-qa.md`, `qa-*.json`, `contrast.json` — выполненные проверки и их границы.

Для локального просмотра из корня репозитория:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory Design/system-2026-09-07
```

Откройте http://127.0.0.1:4173/index.html. Статические HTML также доступны с диска; некоторые браузеры ограничивают переходы между локальными iframe, поэтому локальный сервер предпочтителен. Внешние шрифты/CDN не требуются.

Атлас использует синтетические данные и демонстрационные переходы. Экспорт, воспроизведение, публикация, звонки, SMS и операции аккаунтов не подключены к сервису. Смена страницы или состояния сбрасывает пример; переключение темы сохраняет введённое; это каталог макетов, а не модель постоянного хранения данных. Некоторые второстепенные кнопки показывают пояснение вместо реального действия.

Рабочая папка `sources/` содержит свидетельства исходного приложения, включая данные локальной учётной записи. Она исключена из переносимого ZIP и публичной галереи. Два немецких документа используют seed-источник; см. `content-provenance.json`.

Production-файлы приложения не изменены. Перенос начинается отдельным этапом после согласования новых страниц.
