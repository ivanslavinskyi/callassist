# Expense icons

Official Heroicons v2.2.0, 24px outline, MIT license.
Source: https://github.com/tailwindlabs/heroicons/tree/v2.2.0/optimized/24/outline

The files retain the upstream SVG geometry. Names are kept or shortened to match
the expense category mapping (`signal`, `phone`, `microphone`, `language`,
`document-text`, `clipboard-document-list`, `chevron-right`,
`exclamation-triangle`, `information-circle`). The upstream license is preserved
in the parent brand directory as `heroicons-LICENSE`.
