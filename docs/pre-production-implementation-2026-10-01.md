## Миграции и совместимость

Новые SQL 0095–0099 дополняют каталог, не переписывая ранее применённые миграции.
Проверка заполненной схемы до 0094 подтверждает сохранение остатков и резервов
кредитов, согласований планов, review receipts, текстовых свидетельств разговора
и старых записей экспорта. Отсутствующие исторические метаданные не восстанавливаются
из сегодняшней конфигурации. Backfill отклонённых планов по умолчанию работает
в dry-run и не рассылает старые события. Изменение политики для новых пользователей
не запускает массовую выдачу существующим аккаунтам.

Релизный helper и rollback-only CMS preflight согласованы с каталогом до 0099.
Автоматический rollback на несовместимый старый каталог не допускается. Конкретные
операционные команды, topology и release checklist находятся в локальном ранбуке.

## Границы результата

- Реальное ускорение подготовки требует новых stage percentiles и error rates после
  выпуска; тесты подтверждают deadline/очереди, но не скорость внешнего провайдера.
- Аудио: 64 MiB на запись, 250 MiB аудио на архив и отдельный лимит 250 MiB JSON.
  Автоматических томов нет; слишком большой период явно отклоняется с предложением
  сузить диапазон. Пропуски и partial availability отражены в manifest.
- Экспорт не восстанавливает удалённое/просроченное аудио и не расширяет retention.
  Уже скачанную локальную копию отозвать технически невозможно.
- Alert delivery требует существующей рабочей email-конфигурации, enabled settings
  и верифицированных superadmin recipients. Реальная доставка здесь не проверялась.
- Legacy Realtime/hybrid fallback и нужные immutable-plan compatibility adapters
  сохранены; они не объявлены dead code по одному лишь отсутствию в default path.
- Romansh и остальные переводы имеют автоматическую проверку покрытия; редакторская
  проверка языка остаётся отдельной задачей качества контента.
