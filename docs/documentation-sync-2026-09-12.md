## Обнаруженное ограничение инструмента

CLI `run-real-call-drill.mjs` сохраняет старое тело approve-and-start: revision и
snapshotHash без review evidence. Для нового плана policy v2 без существующего
receipt хранилище возвращает `CALL_REVIEW_REQUIRED`. Текущий UI передаёт нужное
подтверждение; его путь запуска описан в [инструкции тестовых звонков](real-provider-drills.md).

Это подтверждено сопоставлением [runner](../apps/api/scripts/run-real-call-drill.mjs)
с [созданием receipt в PostgreSQL](../apps/api/src/storage/postgres-call-text-store.ts)
и [проверками контракта](../apps/api/src/storage/call-text-repository.test-suite.ts).
Старый fake-server harness этого несовпадения не проверяет. Исправление CLI и его
интеграционной проверки внесено в R06; программный код в этой задаче не менялся.
