# Кредит за состоявшийся разговор — 14 сентября 2026

> Historical implementation checkpoint. The agreed substantive-answer policy remains,
> but realtime qualification and immediate post-consent refunds were replaced on
> 2026-09-15 by [final assessment and deferred settlement](post-call-assessment-diagnosis-2026-09-15.md).


Согласованное правило: кредит используется после согласия адресата и **первого
содержательного ответа по задаче**. Успешное решение задачи не требуется. Этот
checkpoint заменяет прежнее списание по факту соединения; основной backlog остаётся
в [родмапе](mvp-plan.md).

## Поведение

| Событие | Пользовательский кредит |
| --- | --- |
| Запуск звонка | Один кредит резервируется |
| Соединение, согласие, приветствие, готовность слушать | Резерв сохраняется; окончательного списания нет |
| Ответ по задаче, в том числе отрицательный факт, «не знаю», направление в другой отдел | Кредит используется один раз |
| Подтверждение получения согласованного сообщения после его передачи | Считается содержательным ответом |
| Молчание, автоответчик, немедленный отказ, только приветствие/согласие | Без подтверждённого ответа резерв возвращается при завершении |
| Ошибка или неоднозначность классификации | В пользу пользователя: без подтверждения резерв возвращается |
| Повторный callback или поздний ответ классификатора после возврата | Повторного списания и отмены возврата нет |

Расходы Twilio/OpenAI и общий бюджет USD учитываются отдельно. Возврат
пользовательского кредита не отменяет уже понесённые расходы провайдеров и не
сбрасывает ограничения на попытки звонка. Старые завершённые операции журнала
сохраняют историческую семантику; пересчёт старых звонков не выполнялся.

## Реализация и границы

Соединение больше не создаёт `call_charge`. Realtime bridge после согласия и
воспроизведения вступления сохраняет реплики и передаёт пару «ассистент — адресат»
в отдельную текстовую классификацию. Она не произносится и не добавляется в основной
контекст разговора. Использован [документированный out-of-band response OpenAI
Realtime](https://developers.openai.com/api/docs/guides/realtime-conversations).
Текст задачи и реплик рассматривается как недоверенные данные. Для положительного
решения требуется допустимая категория и точная цитата из ответа адресата.

Обработка не привязана к EN/DE интерфейсу: классифицируется исходный язык разговора.
Ограничение — один запрос одновременно, максимум восемь за звонок и восемь секунд
на запрос. При обрыве, таймауте, исчерпании попыток или отсутствии надёжного текста
позднее содержательное общение может остаться неподтверждённым: тогда кредит
возвращается. Это сознательная консервативная граница беты.

PostgreSQL дополнительно проверяет текущую попытку, запись после согласия,
принадлежность и роли реплик, временной порядок. Миграция
`0071_conversation_credit_evidence.sql` добавляет в неизменяемый журнал версию
правила, категорию и идентификаторы подтверждающих реплик. Текст реплик не копируется
в журнал; удаление содержимого звонка остаётся возможным. Единственный индекс
settlement разрешает гонку со штатным завершением/возвратом. Дополнительное событие
телеметрии записывается после commit; журнал остаётся источником истины.

Автоматические проверки подтверждают протокол и защиту учёта, **не безошибочность
семантического решения модели**. Перед публичным тестированием нужны реальные
EN/DE звонки: согласие без ответа, немедленный отказ, обычный/отрицательный ответ,
«не знаю», другой отдел, передача сообщения и обрыв во время ответа. Для остальных
языков нужны отдельные голосовые пробы. В этой сессии звонки и платные модельные
запросы не запускались.

## Проверки

Покрыты: отсутствие списания до содержательного ответа; повторные события;
недостаточные/чужие доказательства; поздняя классификация после возврата; гонка
классификации и завершения; восстановление после рестарта; отсутствие озвучивания
служебной классификации; строгий разбор ответов на нескольких языках. В частности,
шесть новых PostgreSQL integration cases и 55 тестов Realtime bridge проходят.
Полный набор: **1 212 passed / 1 timeout**, 147 файлов, свежая изолированная БД.
Во время параллельной production-сборки существующий тест восстановления worker
превысил 15 секунд; после окончания сборки отдельный повтор **всех 22 тестов
PostgresCallRepository прошёл**. Это не записывается как полностью зелёный единый
прогон. Предшествующие неудачи двух проверок CMS были устаревшими ожиданиями порядка
блоков; ожидания исправлены, затем обе группы прошли (45 тестов).
Lint, typecheck и production build — по 3/3 пакета. Сборка использовала отдельную директорию
Next; автоматически изменённые конфигурационные файлы восстановлены.
Результаты находятся в `Design/conversation-credit-2026-09-14/`.
